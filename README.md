# 康熙南宫县城 · 三维复原

依据清康熙十二年（1673）《南宫县志》卷首〈县城图〉与卷二〈营建志〉制作的可交互三维县城复原网页。

- 建筑位置取自县城图（不按比例的示意图），各建筑形制依据志文记载，属于示意性复原。
- 支持轨道浏览、第一人称漫步（WASD 键移动）、小地图、点击建筑查看县志原文，以及白天与暮色切换。
- 使用 Three.js r160（CDN 引入）构建，纯静态单页，无需构建步骤。

## 本地运行

直接用浏览器打开 `index.html`，或在本目录运行：

```bash
npx serve .
```

## 资料来源

`assets/` 中的县城图书影取自识典古籍收录的康熙《南宫县志》（HY0143）。
